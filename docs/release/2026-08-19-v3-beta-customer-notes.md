# MITAKO Agent v3 Beta 甲方更新说明

发布日期：2026-08-19

本版重点修复“用户与客服 Agent 对话时说错、做错、把没做的事情说成已经做了”的问题，不改变甲方已有四场景视觉审核口径。

## 客服可直接感知的变化

- 用户只说“我有材料”，系统不会再显示已上传、已收到、已建单或审核中；只有网页真实收到附件后才更新状态。
- 模糊商品咨询不会自动套用其他商品，会要求用户补充商品链接、SKU 或订单行。
- 特典、赠品漏发先核对活动权益，不再错误解释为抽奖概率。
- 发错货和漏发货使用各自的材料说明，不再归入闲聊。
- 用户要求转人工时，只有拿到真实排队凭证才显示“排队中”；失败时显示重试与人工入口。
- 高风险投诉会明确显示责任角色、当前动作、首次响应时效和跟进凭证。
- 地址修改服务未接通或失败时，不会说“已修改”。
- 删除手机号、身份证资料和聊天记录进入独立隐私流程，不再误判为账号换绑。

## 页面变化

- 用户端新增“当前处理状态”，显示未提交、待执行、排队中、未执行成功等明确状态和下一步。
- 人工坐席看到与用户端相同的状态和回执，避免双方口径不一致。
- 生成回复时可点击“停止生成”；停止后可立即重新发送，旧回复不会继续写入页面。
- 已验证桌面、Pad 和手机竖屏，无状态卡横向溢出。

## 当前验收结果

- 15 个固定场景连续运行 3 轮，共 45 次，结构化结果 `45/45` 通过。
- 2026-08-18 人工反馈的 10 个问题均有自动回归用例。
- 全仓自动测试 `1490 passed + 100 subtests passed`。

详细验收见[客服 Agent 用户沟通回归验收](../testing/客服Agent用户沟通回归验收-20260819.md)和[甲方可读问题闭环 HTML](../../甲方沟通交付文档/0819客服Agent用户沟通问题闭环验收报告.html)。

## 需要甲方继续确认

当前仍是 POC / Beta。真实订单、仓库、地址修改、隐私、退款和 CRM 接口尚未全部联通；联通前，系统只给可核验事实、失败状态和下一步，不替甲方执行最终业务动作。上线前仍需甲方客服使用同一批场景做一次人工盲测。
