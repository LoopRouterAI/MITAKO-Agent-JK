# 可观测与 7×24 运维 Runbook

当前已提供的指标：

- 客服：排队人数、当前最长等待、平均等待、转VIP客服率、结案率、升级率。
- 视觉审核：任务总量、成功/失败/排队/运行中数量、平均耗时、最老排队时长。
- 模型调用：任务级累计 Token、估算成本、分通道调用数、失败分段、成本状态和内部工作台重试记录。
- 安全：报告签名密钥 readiness、公开 DTO 与自动化脱敏回归。

当前尚未提供完整生产 APM：结构化返回率、供应商软错误率、连续失败次数、渠道切换次数、原始素材 TTL 执行器和未成年人资料访问审计需要接入甲方指标/日志平台后补齐，不能在 POC 阶段宣称已上线。

告警阈值建议：

- 当前最长等待超过 15 分钟：客服主管介入排班。
- 视觉审核成功率低于 80%：切换备用模型或暂停自动建议，仅保留人工复核。
- 公开报告出现内部字段：立即停止对外展示报告，清理 `public_summaries` 并复跑 smoke。
- 429 连续 3 次：指数退避并切换备用渠道。

排障顺序：

1. 查看 `/api/v1/ops/snapshot`。
2. 以审核 `job_id` 为主关联标识，查看任务 `diagnostics`、`workbench_transport.attempts` 和分通道失败明细；聊天链路再使用 ticket_id/session_id。
3. 检查公开报告是否脱敏。
4. 检查模型渠道限流和 Key 状态。
5. 如涉及未成年人资料，优先确认脱敏和访问权限。
