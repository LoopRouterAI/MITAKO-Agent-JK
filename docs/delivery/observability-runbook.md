# 可观测与 7×24 运维 Runbook

核心指标：

- 客服：排队人数、当前最长等待、平均等待、转人工率、结案率、升级率。
- 视觉审核：审核总量、成功率、结构化返回率、平均耗时、重试率、三场景覆盖。
- 模型调用：软错误率、连续失败次数、最近失败类型、渠道切换次数。
- 安全：公开报告脱敏扫描、未成年人资料访问审计、原始素材 TTL。

告警阈值建议：

- 当前最长等待超过 15 分钟：客服主管介入排班。
- 视觉审核成功率低于 80%：切换备用模型或暂停自动建议，仅保留人工复核。
- 公开报告出现内部字段：立即停止对外展示报告，清理 `public_summaries` 并复跑 smoke。
- 429 连续 3 次：指数退避并切换备用渠道。

排障顺序：

1. 查看 `/api/v1/ops/snapshot`。
2. 查看服务日志中的 ticket_id、session_id、review_id。
3. 检查公开报告是否脱敏。
4. 检查模型渠道限流和 Key 状态。
5. 如涉及未成年人资料，优先确认脱敏和访问权限。
