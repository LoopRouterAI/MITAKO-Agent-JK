# 客服 Agent 与私域 Agent 正式接入前人工 UAT 指南

版本日期：2026-07-16
测试阶段：甲方真实系统尚未正式联调前

## 1. 当前可测边界

当前版本可测试用户咨询、订单查询演示、图片/视频审核任务、转人工链路、坐席回复、私域群消息分析、商品事件候选和风险拦截。演示用户、订单、物流、库存、退款和群数据来自本地数据，不代表已连接甲方生产系统。

企业微信、飞书、甲方客服平台、CRM/CDP、商品/抽赏/库存、订单/物流/售后、短信电话和对象存储仍需甲方提供接口与测试环境后联调。

## 2. 客服 Agent 人工 UAT

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 用户隔离 | AI 回复中连续切换全部演示用户 | 消息、订单、卡片、附件和人工状态不串用户 |
| 订单归属 | 输入当前用户、其他用户和不存在的订单号 | 其他用户订单不得回显业务字段 |
| 意图一致 | 分别询问物流、抽赏、库存、有伤、发错、漏发、退款 | 文字、意图、订单和下一动作一致 |
| 卡片噪音 | 连续追问三轮，再要求一句话回答 | 每轮最多一张主卡；一句话请求不强插卡片 |
| 附件审核 | 上传图片、拍摄视频和本地视频 | 创建审核任务并区分完成、失败、低置信状态 |
| 审核回写 | 审核完成后追问结果 | 返回公开结论、置信度、证据报告或可理解的失败原因 |
| 人工转接 | 完成提出、确认、排队、接入、回复、结案 | 用户端与坐席台状态一致，无口头假转接 |
| 人工期情绪 | 接入后发送投诉、辱骂和缓和消息 | 坐席侧情绪更新，原业务诉求不丢失 |
| 刷新恢复 | 排队或人工接入时刷新、断网后恢复 | 状态和消息不丢失、不重复、不重新进入 AI |
| 移动端 | 390x844 完成咨询、上传、转人工 | 无横向溢出、遮挡和不可点击控件 |

## 3. 私域 Agent 人工 UAT

| 场景 | 操作 | 当前通过标准 |
|---|---|---|
| IP 兴趣 | 提交 IP、角色、许愿、晒谷、蹲守消息 | 生成可解释标签和候选动作，不直接自动群发 |
| 舆情风险 | 提交退款、霸王条款、投诉曝光、不发货消息 | 禁推、风险等级、证据和客服任务同时出现 |
| 商品事件 | 提交补货、稀有掉落和库存事件 | 正常群进入待审候选，高风险群被拦截 |
| 重复事件 | 同一 message_id/event_id 连续提交两次 | 不应重复生成客服任务或触达候选；若重复则记录为缺陷 |
| 边界提示 | 查看系统连接状态 | 明确显示演示数据或待联调，不显示“已连接企微” |

## 4. 必须记录的缺陷信息

- 测试时间、页面、演示用户、案件号或消息 ID。
- 输入文字、附件文件名和操作顺序。
- 实际结果、预期结果、截图或录屏。
- 浏览器控制台错误、接口状态码和 `trace_id`。
- 是否可稳定复现，以及复现次数。

不得在反馈文档中记录真实 API Key、Token、用户手机号或未脱敏订单数据。

## 5. 当前已知外部联调项

- 企业微信：入站验签、消息去重、群/用户 ID 映射、出站发送、回执、撤回和私聊。
- 客服平台：工单创建、队列、技能组、坐席状态、消息同步、结案和结果回写。
- 商品系统：SKU、IP、角色、稀有度、库存、上下架、App/小程序链接。
- 订单售后：订单归属、物流、退款、补发、换货和仓库处理状态。
- CRM/CDP：用户 ID 映射、会员、生命周期、价值、兴趣和风险标签。
- 对象存储/转码：签名上传、下载授权、超大视频转码、回调和生命周期。

这些项目在甲方未提供接口前只能完成契约、模拟请求和本地演示，不能写为真实接入完成。
