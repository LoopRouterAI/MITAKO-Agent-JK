# 生产部署与容量规划

当前 POC 已验证本地演示链路，不代表生产压测结果。正式容量规划必须基于甲方真实工单峰值、视频大小、并发坐席数、模型限流和 SLA 重新测算。

建议起步参数：

- 客服 Agent 主服务：2 个以上实例，前置网关做会话粘性或将 SSE 状态外置。
- 人工转接队列：SQLite 仅用于 POC；生产建议 PostgreSQL 或 MySQL，并对接 Redis 锁或数据库条件更新。
- 视觉审核：视频单文件建议小于 300MB；严格审核可从 1fps 提升到 2fps，但需要控制 `max_frames` 和模型上下文。
- 异步任务：视频下载、抽帧、模型审核、报告生成应进入队列；生产建议 Redis + Celery/RQ 或 Java 侧 MQ。
- 限流重试：429、502、503、504 按指数退避；硬错误直接切换备用渠道或进入人工复核。
- 数据保留：原始视频、帧图、公开报告、内部诊断报告分目录保存，生产按甲方合规要求设置 TTL。

上线前必须补充：真实压测报告、峰值 QPS、平均视频大小、模型渠道限额、失败重试成本、人工复核阈值。
