# 测试与验收指南

本文用于客户验证环境和上线前回归，目标是确认用户端、VIP客服工作台、运营后台、业务适配边界和视觉审核工作台稳定可用。

## 推荐顺序

| 阶段 | 目标 | 负责人 |
|---|---|---|
| 自动化回归 | 验证核心接口、鉴权、租户隔离、转VIP客服和后台流程 | 我方研发与测试 |
| 页面冒烟 | 验证用户端、坐席台、运营后台和视觉审核工作台可打开 | 我方测试 |
| 手工验收 | 验证客服负责人关心的业务流程 | 双方项目组 |
| 联调验收 | 替换为客户测试环境接口后验证真实契约 | 双方开发 |

## 默认入口

| 系统 | 端 | URL | 账号说明 |
|---|---|---|---|
| 客服系统 | 用户端 | `/` | 无需登录 |
| 客服系统 | 坐席台 | `/desk` | 使用交付账号登录 |
| 客服系统 | 运营后台 | `/admin` | 使用运营或主管账号登录 |
| 视觉审核 | 工作台 | `http://127.0.0.1:7861/` | 本地启动后访问 |

## 手工验收

| # | 场景 | 期望 |
|---|---|---|
| A-1 | 用户发送订单进度、售后或补件问题 | 返回专业客服建议，页面不暴露底层处理细节 |
| A-2 | 用户触发转VIP客服 | 出现排队卡片，文案只体现客服接待，不出现承接方或内部团队信息 |
| A-3 | 坐席接单并回复 | 用户端和坐席端消息同步 |
| A-4 | 坐席转交或升级 | 状态正确流转，服务记录可追溯 |
| A-5 | 运营后台查看队列、坐席、审批、报表 | 页面无报错、无乱码 |
| B-1 | 上传开箱视频材料 | 自动抽帧并输出证据摘要、置信度和人工复核建议 |
| B-2 | 上传商品有伤图片或视频 | 报告展示损伤位置、证据强弱、需补充材料 |
| B-3 | 上传未成年人资料审核材料 | 报告强调隐私保护、材料完整性和人工确认点 |
| B-4 | 查看视觉审核报告 | 结论优先，证据链可预览，图片用浮层查看，不跳走页面 |

## 通过标准

| 项目 | 标准 |
|---|---|
| 页面质量 | 无乱码、无控制台错误、无内部处理细节泄露 |
| 鉴权 | 未登录访问受保护接口会被拒绝 |
| 租户隔离 | A 租户账号不能操作 B 租户会话 |
| 业务边界 | 验证环境只输出建议，不写入甲方真实系统 |
| 视觉审核 | 能输出证据摘要、置信度、人工复核建议和缺失材料提醒 |
| 合规边界 | 客服 Agent 保持专业同理，不提供陪伴、角色扮演或自动最终裁决 |
