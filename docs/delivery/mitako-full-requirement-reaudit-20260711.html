生产签字阻塞项： 真实企微收发、商品/订单/库存/CRM 回传、飞书协同、对象存储转码、漏发货真实样本、120GB 盲测指标和生产基础设施。

私域 Agent 的真实现状

当前私域 Agent 是可运行的群级 P0：接收群消息和商品事件，更新群标签与风险，生成待审核触达候选，高风险时禁推并创建客服任务。它不是完整的 0708 生产规划全量实现。

  • 已能演示： 群消息 -> 兴趣/许愿/风险 -> 群画像；商品事件 -> 1 万群匹配 -> 待审候选；高风险 -> 禁推 -> 客服任务。
  • 尚未产品化： 向量 RAG、知识发布审核、完整许愿池、晒谷活动、用户生命周期、群疲劳累计、分时机调度、A/B、长期记忆和复盘归因。
  • 尚未真实打通： 企微群、App/小程序事件流、订单库存、CRM/CDP、飞书和真实客服系统回写。

达到“全部完成”还需四个验收包

  1. 外部联调包： 甲方提供 sandbox、字段样例、鉴权、回调和权限；逐接口完成双向验收。
  2. 120GB 质量包： 正负/困难样本盲分，按四场景输出召回率、精确率、人工节省率、成本和失败类型。
  3. 私域二期包： 可控 RAG、长期记忆、用户分层、频控日历、A/B 与运营复盘产品化。
  4. 生产基础设施包： PostgreSQL/Redis/MQ/对象存储、分布式 worker、监控告警、备份恢复和压测报告。
