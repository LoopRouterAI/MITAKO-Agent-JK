验收结论

本轮缺陷已闭环：商品有伤默认全门槛回退已移除，未成年人模板/截图/编辑风险语义已收紧，报告首屏和 API 下一步不再把“建议抽检”写成“逐单 VIP 复核”。

根因与修复

根因 1：事实与业务边界耦合

旧链路把“服务不执行退款”误解释为“服务不能给明确建议”。现已拆成事实、SOP、复审、业务动作四层。

根因 2：默认规则过严

旧商品有伤策略要求所有门槛同时通过。现默认只用核心 SOP 事实形成倾向，其他项进入风险与抽检。

根因 3：资料语义混合

旧未成年人链路混淆材料存在、SOP 有效性、字段一致性和真实性风险。现按独立字段聚合。

根因 4：多个展示层各写一套下一步

旧模型文案可能残留“VIP 复核”。现统一建议聚合层覆盖 API 摘要，报告渲染兼容旧数据并再次校验。
