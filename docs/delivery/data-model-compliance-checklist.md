# 数据安全与模型合规清单

| 类别 | 必做项 | 状态 |
| --- | --- | --- |
| 客户隐私 | 客户 ID、手机号、地址、支付凭证默认脱敏展示 | POC 已设计，生产需接甲方脱敏规则 |
| 未成年人资料 | 只做材料完整性辅助，不自动裁决退款 | POC 已约束 |
| 公开报告 | 不展示模型供应商、Prompt、Token、成本、原始返回 | 已补 smoke |
| 业务接口 | 甲方订单、物流、仓库、清关接口只能 Mock 或契约说明，未接入前不得伪装真实结果 | 已约束 |
| 数据留存 | 原始视频、抽帧、补充图片需要 TTL 和删除接口 | 生产待实现 |
| 模型调用 | 需要记录请求 ID、耗时、软错误、重试，不向普通客服展示内部供应链 | POC 聚合展示 |
| 人工复核 | 高置信度可建议抽检，低置信度必须人工复核 | POC 已设计 |
