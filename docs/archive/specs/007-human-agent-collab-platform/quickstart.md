# Quickstart: 007 人机协同客服平台验收

## 前置

1. `npm run build`（MITAKO_Agent 根目录）
2. 启动后端：`python main.py` → http://127.0.0.1:8001
3. 硬刷新用户端 `/` 与 `/desk`

## 场景 A — 排队与真实接入

1. 用户端场景 3 或申请人工 → 见「正在帮您联系人工客服，当前人工坐席繁忙，正在帮您排队中」
2. `/desk` 选 CS-0816 → 读简报 → **确认阅读并接受转接**
3. 用户端 ≤3s 内变为「已成功联系到人工客服」+ 虾饺退下动画
4. desk 发送回复 → 用户端轮询可见（非固定 mock 话术）

## 场景 B — L5 默认一线接单

1. 触发高情绪转人工（含「起诉」「黑猫」等）
2. 确认 `config/handoff_routing.json` 中 `high_emotion_supervisor.enabled=false`
3. CS-0816 一线可成功接单

## 场景 C — 转同事

1. A 已接入 → desk 点「转交同事」选 CS-0922
2. B 登录身份 CS-0922 → 确认接管
3. 用户端见系统提示负责专员变更；B 回复用户可见

## 场景 D — @虾饺 旁听

1. 人工已接入 → 用户发送 `@虾饺 帮我和专员说一下我很着急，想确认发货时间`
2. 虾饺回复帮催类话术，不出现退现金/超额赔偿承诺
3. desk 对话区可见 observer 消息

## 场景 E — 富文本一致

1. 简报或历史含 `#优先发货特权#`
2. 用户端与 desk 侧栏/对话区高亮样式一致
