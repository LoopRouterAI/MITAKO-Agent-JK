# MITAKO 虾淘私域社群 AI 运营系统设计 (v1.0)

## 1. 项目背景与商业价值
* **现状**：10,000+ 个企业微信私域大群（约100万人），目前处于“纯发活动”状态。
* **商业价值**：激活百万私域流量，提升**复购率**；实现秒级危机阻断，防止负面情绪在群内传染。
* **定位**：“社群福利官 + 节奏大师 + 舆情监控雷达”。

## 2. 核心技术架构 (面向 Coding Agent)
* **对接通道**：企业微信/微信官方 API 或合法稳定的 Hook 方案（视甲方合规要求而定）。
* **事件驱动总线**：Kafka 或 RabbitMQ，处理万群并发的消息洪峰。
* **NLP 情绪引擎**：由LLM判断用户的情绪，受到@时与用户互动（但可能会有大量的文本对话成本，尽量选足够便宜的模型）。
* **RAG 知识库**：MaxKB 或 Dify，存储《谷子黑话词典》、《退换货政策》、《最新发货公告》。

## 3. 核心功能与落地实现机制

### 3.1 谷子词典与日常问答 (防小白流失)
* **痛点**：新手不懂“出荷、大赏、吧唧、流麻、抱盒”，人工客服没空教。
* **实现**：
  * 触发词机制：群内出现 `@虾饺 什么是出荷` 或 `求问...` 时触发。
  * 流程：提取关键词 -> RAG 检索《二次元黑话库》 -> LLM 润色为可爱口吻 -> 发送到群内。
  * *技术细节*：设置冷却时间（CD），同一个群5分钟内不重复回答相同问题，防止刷屏。

### 3.2 自动化吃谷雷达 (促转化)
* **痛点**：新品开赏或稀有款掉落时，触达率低。
* **实现**：
  * **接口对接**：监听甲方后端的 `ItemDropEvent`（商品掉落事件）Webhook。
  * **智能分发**：根据群标签（如“原神群”、“排球少年群”）精准推送。
  * **展示形式**：发送精美的图文链接或企微小程序卡片，附带“限时抢购”煽动性文案。
  * *示例话术*：“🚨前方高能！《蓝色监狱》凪诚士郎隐藏款刚刚在XX赏池掉落！仅剩最后3发，谁来捡漏？[小程序链接]”

### 3.3 群内情绪监控与公关预警 (核心护城河)
* **痛点**：一人带头抱怨吞烫/不发货，全群跟风，导致群报废。
* **实现机制 (Sliding Window Sentiment Analysis)**：
  1. **实时监听**：抓取群内所有文本，过滤无意义聊天。
  2. **关键词与情感双重判定**：
     * 命中高危词（退款、黑猫、垃圾、吞烫、跑路）。
     * 本地 NLP 模型判定该句子情感得分为负面。
  3. **阈值触发**：同一个群在 10 分钟内，出现 3 条以上高危负面消息。
  4. **执行动作 (阻断与隔离)**：
     * **对内报警**：通过企微应用，立刻给该群的运营主管发送警报：“⚠️ [原神3群] 爆发集体客诉风险，请立即介入！”
     * **对群安抚 (AI自动)**：AI 在群内 `@带头用户` 并回复：“大家稍安勿躁，虾饺看到大家的反馈啦！为了保护大家的隐私和订单安全，涉及到具体订单进度的问题，虾饺已经私信您啦，请注意查收哦~ <meme:鞠躬>”
     * **私聊承接**：AI 自动向该用户发送私聊消息，将其引导至 1对1 的 AI 客服流程（对接文档一的系统）。

## 4. 私域 Agent System Prompt 示例

```text
# Role
你是 MITAKO 虾淘的官方玩家群管理员。你的任务是活跃群气氛、解答基础问题，并化解群内的负面抱怨。

# Rules
1. 你的回复必须简短（不超过50字），因为在群聊中长篇大论会被无视。
2. 严禁在群里与用户辩论对错。
3. 遇到用户抱怨发货慢、质量差，统一话术引导私聊：“宝宝别急，具体订单问题虾饺已经给您发私信啦，马上帮您查！”
4. 遇到用户问“什么是xx”，用最接地气、二次元的语言解释。

# Examples
User: 到底什么时候发货啊？都半年了！
AI: 抱歉让宝宝久等了！<meme: 跪地> 因为每个人的订单批次不同，虾饺已经通过私信找您啦，帮您单独催单！
```

## 5. 商业报价与增值模式建议

* **基础实施费**：20万（包含企微群管机器人基建、吃谷雷达打通、基础问答）。
* **高阶风控模块（按年订阅）**：15万/年（包含情绪监控引擎、突发舆情自动隔离流转系统）。
* **算力与通道费**：按实际消耗 Token 与企微接口调用量实报实销（约 3-5万/年）。
* **总计**：首年约 35万 - 40万。
