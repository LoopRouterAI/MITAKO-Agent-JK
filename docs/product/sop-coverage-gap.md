# SOP 覆盖差距与当前状态

本文件记录当前客服 Agent 与甲方 SOP 的覆盖关系。旧版陪伴/角色扮演服务线已经封存，不再参与当前 SOP 覆盖评估。

## 当前已覆盖

| 场景 | 当前能力 | 人工边界 |
| --- | --- | --- |
| 发货慢/清关慢/仓库慢/物流慢 | 情绪承接、订单状态解释、催办建议、转VIP客服 | 不能承诺具体到货时间或替甲方改物流状态 |
| 商品不好/要退货 | 引导补充订单、照片、视频、原因，生成售后任务 | 退款、拒赔、补发必须人工或甲方系统裁决 |
| 商品有伤 | 进入视觉审核工作台，输出证据链、置信度、人工复核建议 | AI 只提供参考，人工抽检/复核 |
| 开箱视频/疑似发错货 | 支持视频抽帧、补充图片、订单 SKU/规格上下文、连续性检查 | 需要甲方主数据和出库记录支撑最终处理 |
| 未成年人资料审核 | 支持材料完整性和一致性检查 | 必须人工终审，不自动退款 |
| VIP客服接手 | 工单摘要、用户情绪、已收集材料、下一步建议 | 坐席负责最终沟通和业务动作 |

## 仍需甲方提供

- 订单、SKU、规格、商品主数据和随机/盲抽规则。
- 仓库出库、物流轨迹、售后状态、退款/补发权限接口。
- 已人工确认的正负样本，至少覆盖三类审核场景的通过/不通过样本。
- 客服 SOP 文档、禁用话术、补偿政策、升级规则。
- Java 后台回调地址、鉴权方式、幂等字段和错误码规范。

## 当前改造重点

1. 把三类视觉审核从混合入口优化为独立入口，减少客服选择成本。
2. 工作台支持文件夹扫描、队列、并发、重试、失败原因、报告浮层预览。
3. 客服 Agent 与人工台共享同一工单上下文：用户诉求、历史对话、订单、物流、上传材料、审核报告。
4. 报告首屏先给结论，再给证据链、时间戳、补充图片和下一步处理建议。
