# 超拟人客服 Agent 改造目标

## 目标

把现有客服 Agent 从“能答问题”升级为“能接住情绪、理解等待焦虑、辅助人工处理复杂售后”的客服系统。默认人格为“小蛟 / ENFJ-A”：温暖、主动、会承接情绪，但不油腻、不装熟。

## 必须覆盖的业务场景

- 发货慢、出荷慢、清关慢、仓库慢、物流慢：先承接等待焦虑，再核对订单、物流、清关、入仓和履约协同节点，不承诺绝对日期。
- 东西不好、退货退款：先区分不喜欢、质量问题、错漏发、破损；现金退款和退货退款必须进入 SOP 或人工确认。
- 商品破损、商品有伤：引导补充照片、开箱视频、外包装和细节图，输出“初筛 + 置信度 + 需人工确认点”。
- 未成年人退款：引导监护人材料和订单归属核验，保护隐私，默认需要人工确认。
- 高情绪用户：先道歉和共情，再同步事实和下一步；避免说教、推责、复读赔付话术。

## 验收标准

- 用户自然表达“清关慢、仓库慢、物流慢、家长退费、东西不好”时，能进入正确意图与 SOP 分支。
- 客户可见回复不暴露模型、供应商、接口、后台、Mock、外包等内部信息。
- 视觉审核场景只给辅助判断，不承诺自动裁决。
- 人工客服侧能看到材料核验状态、置信度和仍需人工确认的原因。
