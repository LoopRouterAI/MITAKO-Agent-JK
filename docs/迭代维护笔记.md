## 2026-07-08 17:05:00｜0708甲方复测阻断项最终收口：附件可见闭环、硬拒绝与全交付口径清理

本轮来源：多 Agent 复审指出上一轮仍有三类阻断风险：越权附件在聊天接口中只是静默丢弃而非硬拒绝；用户端和 VIP客服工作台虽然后端保存了图片，但页面看不到图片凭证；交付文档、脚本、更新日志和内部设计资料仍残留旧对客口径。

本轮最终修复：

- `/api/v1/chat` 和 `/api/v1/handoff/user-message` 改为附件硬校验：请求体只要包含不属于当前 `user_id/session_id/tenant_id` 的附件，直接返回 `403 invalid_attachment_scope`，不再继续进入 Agent。
