## 必须修复的根因

1. 商品有伤摘要必须分开表达“损伤事实”和“责任/SOP 门槛”。伤点已确认时不能只剩“请补材料”，应说清“已看到伤点，但开箱责任链仍未闭环”。
2. 包裹面单匹配是关键门槛，不能只信模型布尔值。`517066` 已证明模型可在无清晰视频面单时错误输出匹配；在完成受信比对或二次核验前必须保持未知。
3. 漏发必须消费完整拆单、分包、物流和仓库基线。甲方接口尚未接入时，报告可以给出精准查询项，但不能把单包裹视觉差额写成终态。
4. 未成年人报告要把五类材料的“类别存在”和“字段有效”分开。类别出现不代表承诺书支付信息、主副卡完整号码、户口本封面等字段已经齐全。
