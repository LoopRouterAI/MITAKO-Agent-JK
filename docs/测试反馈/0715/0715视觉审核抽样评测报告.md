## 重部署后结论

后端重部署后，视觉审核链路已经恢复：本轮 102 个成功创建的审核任务全部返回 `SUCCEEDED`，均拿到了 `predicted_label` 与 `confidence`。这与上一轮 102 个任务全部 `FAILED`、`predicted_label/confidence` 为空相比，说明模型复核链路已可用。

但当前审核准确率仍不满足生产可用要求：102 个可比样本中与人工标签一致 45 个，一致率为 44.12%。其中负样本识别能力最弱：31 个负样本中仅 1 个被 Agent 判为负样本，负样本召回率约 3.23%，存在明显“把人工拒绝/不通过样本判成 positive 或 review”的风险。

另有 7 条样本在创建审核任务时被 API 拒绝，未进入审核队列：6 条为 Nginx `413 Request Entity Too Large`，1 条为 `415 invalid_review_asset_content`。说明模型链路已修复，但线上网关/上传限制仍未完全与接口契约对齐。
