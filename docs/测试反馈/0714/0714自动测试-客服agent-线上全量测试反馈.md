## 一、总体结论

0711 线上版本相比 0709 版本有明显进步：用户端的订单查询、负面情绪识别、电话提醒诉求、L4 不强制转人工、角色权限、三类视觉审核入口等关键能力已经可以演示。

### 1. 切换用户后旧订单和旧卡片残留

测试路径：先用“小圆”咨询 `#026102`，再切换到“花腔/阿光/监护人”。

影响：客户会认为系统存在跨用户上下文污染，严重时会被理解为数据隔离问题。

### 2. 原始代码包仍有订单焦点优先风险

桌面原始 zip `agent.py` 中查询订单焦点仍为：

```python
focus_ref = active_order_id or explicit_order_ref
```

这意味着前端残留的 `active_order_id` 会优先于用户本轮明确输入的订单号。线上本轮“切换到小圆后查 #026102”返回正确，但代码包本身仍建议改为：

```python
focus_ref = explicit_order_ref or active_order_id
```

证据：

![显式查询 #026102 线上结果正确](/Users/lizhijing/Desktop/MITAKO_Agent_0711线上全量测试证据_20260714/03_用户端-跨用户订单026102复查.png)
