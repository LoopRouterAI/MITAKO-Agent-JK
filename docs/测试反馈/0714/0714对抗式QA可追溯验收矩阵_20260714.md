## 2. 全局放行规则

| 等级 | 放行阈值 |
| --- | --- |
| P0 | 全部 100% 通过；不得存在跨用户/跨订单、错误业务动作、数据泄露、假转接、审核结论丢失、发布包无法验收。任一失败即禁止客户自由验收。 |
| P1 | 确定性用例 100% 通过；语义/体验评测总通过率不低于 95%，且单场景不低于 90%；不得出现业务事实冲突。 |
| P2 | 总通过率不低于 90%，无阻断主流程的问题；可作为有期限的体验改进项。 |

状态说明：`已覆盖` 表示当前已有自动化和证据；`部分覆盖` 表示 smoke 或单元检查存在但没有覆盖甲方操作路径；`缺失` 表示当前没有可自动判定的验收。
