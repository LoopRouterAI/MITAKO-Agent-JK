# POC 审查 Demo 提交前检查清单

更新时间：2026-07-04

## 当前目标

提交前必须满足三件事：

1. 客服主站右侧观察面板默认可见、可折叠，但普通链接不展示模型供应商、Token、Prompt、接口、权重调参等内部信息。
2. 视觉审核工作台按三个独立业务队列进入：开箱视频、商品有伤、资料审核；客服每次只提交一个队列任务。
3. 默认报告只输出客服可复核摘要；模型、渠道、Token、成本、端点和参考文档只允许出现在内部报告。

## 浏览器目检

1. 客服主站：`http://127.0.0.1:8000/`
   - 桌面端右侧观察面板默认展开。
   - 移动端主对话优先，右侧面板通过悬浮按钮打开。
   - 普通链接不展示内部控制项。
   - `http://127.0.0.1:8000/?ops=1` 才显示内部运营控制项。

2. 视觉审核工作台：`http://127.0.0.1:7861/`
   - 三个入口分别是开箱视频队列、商品有伤队列、资料审核队列。
   - 切换入口时材料要求、默认取证密度、提交按钮文案同步变化。
   - 上传卡片支持点击和拖放，并明确 mp4/mov/m4v/webm/mkv、最大 300MB。
   - URL 区域明确支持 YouTube、B 站、抖音、TikTok、小红书公开链接和公开视频直链，并说明平台限制。
   - 移动端隐藏大幅装饰区，表单优先，提交按钮保持可触达。

## 已知边界

1. 真实甲方后台、退款、补发、拒赔、订单接口没有接入；当前只做 POC 辅助审核和本地 Mock 边界。
2. 视觉审核输出不能承诺自动裁决，只能作为人工复核证据链和客服提效工具。
3. URL 解析依赖公开可访问链接、平台策略和 `yt-dlp` 能力；登录可见、地区限制、平台风控链接应改为本地上传。
4. 公开视频直链可能需要完整下载，平台 URL 会尝试下载前置片段；大素材最终仍建议甲方 App/小程序直接上传源文件或关键片段。
5. 当前命令行视觉审核 Demo 已收敛为 Gemini 3.5 Flash 单样本审核；模型选型矩阵和多模型双盲不再作为这个 Demo 的验收项。
