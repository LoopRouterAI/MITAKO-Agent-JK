# 升级日志 · 2026-07-11

## 新增系统

- 独立审核服务 `review_service/`：案件、批次、幂等、重试、指标和 HTML 报告。
- 私域 Agent P0 `private_domain/`：群消息、群风险、商品事件、候选触达和客服任务。
- Java/OpenAPI 交付材料：采样规划、多文件案件、批次查询和部署说明。

## 视觉审核升级

- 四类业务场景：商品有伤、发错货、漏发货、未成年人退款资料。
- 自适应、1fps、2fps 和自定义抽帧。
- 密集帧按 24 帧分段并发，聚合 Token 和估算成本。
- 支持完整 source_record、多图、多视频、订单/商品/仓库/物流/对话/SOP 上下文。
- 大图片压缩；大视频返回对象存储转码建议。
- 人工标签和标准答案禁止进入模型输入。
- 公开报告清理模型渠道、Key、Prompt、原始响应和内部路径。

## 客服 Agent 升级

- 短负面句保持上下文，不再降为闲聊。
- L4 提示人工但不强制入队；L5/投诉/法律风险才强制升级。
- 人工服务期间继续实时更新意图与情绪。
- 视觉审核完成/失败结果均可进入客服上下文。
- 补偿待审批不再被误判为必须转人工。

## 私域 Agent 升级

- 群级 IP、许愿和风险信号提取。
- 高风险群暂停营销并创建客服任务。
- 商品/库存事件按 IP、角色、库存和风险生成候选。
- 1 万群本地规模验证通过。

## 工程与交付

- OpenAPI 路径扩展到当前主应用完整契约。
- 客户 ZIP 加入审核服务和私域 Agent 运行时。
- 发布门禁检查源码、密钥、内部术语、历史报告和运行数据。
- 发布包完成独立解压导入和 63 条应用路由注册验证。
