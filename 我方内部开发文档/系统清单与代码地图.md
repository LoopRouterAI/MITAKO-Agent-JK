# 系统清单与代码地图

版本：2026-08-14

## 1. 系统总览

```text
用户/客服浏览器
  -> FastAPI 主服务
     -> 客服 Agent
     -> 人工客服与后台
     -> 审核编排服务 -> 视觉审核服务
     -> 私域 Agent P0
     -> SQLite/运行时数据

甲方 Java/网关
  -> /api/v1/auth/*
  -> /api/v1/review/*
  -> /api/v1/private-domain/*
  -> /metrics 与 /api/v1/ops/snapshot
```

## 2. 模块清单

| 系统 | 代码入口 | 存储 | 外部依赖 | 当前边界 |
|---|---|---|---|---|
| 用户端客服 | `src/App.jsx`、`src/hooks/useChatSSE.js` | 会话/订单样例 | 主服务 SSE | POC 可演示 |

| 鉴权 | `auth/` | SQLite | JWT/SSO 适配 | 生产应接甲方账号体系 |

## 3. 审核服务数据流

```text
Java 提交 metadata + files
  -> ReviewCaseMetadata 校验、租户与标签隔离
  -> 程序盘点业务字段、媒体、哈希、重复项和技术状态
  -> 图片独立 WebP / 超阈值视频完整时长 VP9 代理
  -> worker 调用视觉服务 /api/review-folder
  -> 场景专属 Prompt + Schema 提取可见原子事实
  -> 程序计算材料齐全性、受信对账、SOP 与人工路由
  -> 生成公开安全 DTO、场景双层报告、Token 与成本审计
  -> 写回任务
  -> Java 查询 job 或 batch
  -> 获取公开 HTML 报告
```

核心文件：

- `review_service/router.py`：OpenAPI 路由。
- `review_service/schemas.py`：案件、采样、任务和批次模型。
- `review_service/service.py`：创建任务、调用视觉服务、聚合和恢复。
- `review_service/store.py`：SQLite 任务状态和批次聚合。
- `review_service/material_readiness.py`：程序盘点和四场景材料齐全性。
- `review_service/decision_policy.py`：商品有伤等确定性 SOP 决策。
- `review_service/advisory_assessment.py`：客服动作、人工级别和业务边界。
- `prompts/visual_review/scenes/`：四场景 Prompt 规则入口。
- `prompts/visual_review/schemas.py`：严格结构化响应契约。
- `configs/model_catalog.py`：模型能力、实验状态和成本口径。
- `poc/visual_review_poc/media_preflight.py`：图片 WebP 和送审执行诊断。
- `poc/visual_review_poc/native_video_proxy.py`：全时长 VP9/显式 HEVC 代理。
- `poc/visual_review_poc/model_selection_e2e.py`：媒体准备、分段调用和结果聚合。
- `poc/visual_review_poc/native_video_perception.py`：完整视频事实投影和证据门禁。
- `poc/visual_review_poc/sampled_video_perception.py`：默认关闭的受控 1 FPS 回退事实聚合。
- `poc/visual_review_poc/object_continuity.py`：逐帧主体时间线和离镜保护。
- `poc/visual_review_poc/damage_causality.py`：动作前/中/后因果链和成因边界。
- `poc/visual_review_poc/fulfillment_reconciliation.py`：应发/实收清单和跨包裹对账。
- `poc/visual_review_poc/report_renderer.py`：公开报告。
- `poc/visual_review_poc/sample_evaluation.py`：离线样本表解析与探索性一致率，不参与生产推理。

`workbench_server.py`、`model_selection_e2e.py`、`main.py` 和 `agent.py` 仍是历史大型模块。当前先以集中 Prompt/Schema、媒体 helper、确定性策略和测试边界降低变更风险；后续按现有职责拆分，不做无行为收益的框架重写。

## 4. 私域 Agent 数据流

```text
企微群消息契约
  -> 兴趣/许愿/风险快筛
  -> 群标签与健康状态
  -> 高风险禁推 + 客服任务

商品/库存事件契约
  -> 扫描群画像
  -> IP/角色/库存/风险匹配
  -> 待审核触达候选
```

当前没有真实企微发送、用户级长期记忆、完整 RAG、A/B 或自动群发。

## 6. 生产替换点

- SQLite -> PostgreSQL。
- 本地线程池 -> Redis/RabbitMQ/Kafka + 分布式 worker。
- 应用服务器上传大文件 -> 对象存储直传 + 转码回调。
- 本地 JWT 账号 -> 甲方 SSO/网关。
- Mock 业务适配 -> 甲方订单、库存、CRM、企微和飞书测试接口。

替换应保持 `/api/v1/review/*` 和 `/api/v1/private-domain/*` 的外部契约稳定。
