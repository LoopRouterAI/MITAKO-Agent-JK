```bat

npm run build
一键启动-Windows.bat
```

```bat

```

## 开发边界

- 客服 Agent 的人格化只用于专业客服语气和同理心，不做陪伴或角色扮演。
- 视觉审核结果只作为人工客服参考，不自动退款、补发、拒赔或写入甲方真实系统。
- 新增甲方接口时必须经过适配层，不允许让 Agent 直接调用甲方生产接口。
- 对甲方展示页面和报告不得暴露模型名、渠道、密钥、内部 prompt、token 或调试日志。
