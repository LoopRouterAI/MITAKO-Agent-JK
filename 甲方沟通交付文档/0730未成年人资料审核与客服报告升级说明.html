这次到底改了什么

默认不依赖不存在的接口

身份、运营商和支付在线验真默认关闭。系统会明确说明“没有做法定验真”，但不会因此要求每一单都转 VIP 客服。

51/62 张图片全部看完

单案图片量会动态分批和并发处理。真实任务已验证 51/51、62/62 全部接收与处理，不静默截断。

黄色风险只建议抽检

缺少拍摄信息、单个疑似编辑提示、部分字段看不清，都会标黄并给出图片链接，但不单独阻断。

红色问题才要求重点复核

明确字段冲突、字段比对失败、多项疑似编辑互相印证，或甲方主动启用严格验真时，才要求人工重点查看。

报告先说结论和下一步

首屏先展示事实结论、证据分数、是否需要人工、下一步怎么做；五类材料可点击原图回看，末尾再次给客服行动建议。

网页与 API 使用同一结果

网页单件、工单文件夹和正式异步 API 使用同一策略与报告链路；API 可选择只返回字段，或同时生成 HTML。

客服怎么读新的交通灯报告

绿色：可继续

五类材料和可见字段没有明显矛盾。Agent 给出事实建议，甲方系统仍按自身规则决定最终动作。

黄色：建议抽检

资料齐全但有非阻断疑点。客服只看标黄图片，不需要整单从头再审。

红色：重点复核

存在明确冲突、技术失败或多项高风险证据。报告会说明具体图片和理由。

未成年人资料现在检查什么

检查层系统会做系统不会冒充
五类材料身份证明、监护关系、双方签字承诺书、订单/支付凭证、手机号归属证明不会因为图片多就只看前 40 张
可见字段一致性比较图片中看得清的年龄、关系、签署主体、订单支付和手机号材料不输出姓名、证件号、手机号或 OCR 原文
图片风险提示拍摄信息是否缺失、是否有疑似编辑线索，并给出风险百分比和证据图片风险百分比不是图片真伪概率
权威在线验真保留未来对接开关；甲方明确要求时可启用严格模式当前没有接口时不会宣称已权威验真

甲方如何复测

  1. 网页端选择“资料审核”，上传单个工单文件夹；可使用 51 张或 62 张图片样本验证全量处理。
  2. 查看首屏是否写清“可继续、建议抽检或重点复核”，并确认理由与下一步一致。
  3. 打开“五类材料核对”，点击图片编号和证据缩略图，确认原图可放大。
  4. 通过正式接口提交同一案件，轮询任务状态，并读取结构化字段或 HTML 报告。
  5. 盲测时不要把目录标签、人工结论、annotation.json、reply.json 或最终退款结果送入审核请求。

默认策略是视觉初审，不依赖外部验真。若甲方未来明确要求每单做身份/运营商在线验真，再开启严格模式并联调对应接口。
