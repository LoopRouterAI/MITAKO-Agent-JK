# POC 审查 Demo 使用与边界说明

更新日期：2026-07-03

## Demo 覆盖范围

本次 Demo 覆盖两类能力：

1. 客服 Agent 主链路：用于演示智能客服对物流慢、发货慢、售后退款、商品破损、未成年人资料等问题的理解、安抚、记录整理和人工接入协作。
2. 视觉审核工作台：用于演示开箱视频、商品有伤、资料审核三类高人力场景的证据整理、风险提示和人工复核建议。

## 视觉审核三类入口

1. 开箱视频队列：检查开箱过程连续性、箱体或商品是否离开镜头、疑似剪辑风险和补拍建议。
2. 商品有伤队列：整理破损、划痕、变形、碎裂等可见证据，并提示是否需要补拍局部特写或完整角度。
3. 资料审核队列：辅助检查材料完整性、脱敏状态和补件线索，最终结论必须由人工复核确认。

## 素材提交方式

1. 本地上传：支持 mp4、mov、m4v、webm、mkv，单文件最大 300MB。
2. 公开视频链接：优先支持 YouTube、B站、抖音/TikTok、小红书公开分享文本，以及常见视频直链。
3. 如果链接需要登录、地区受限、平台禁止读取或文件过大，请改为本地上传关键片段。

## 业务边界

本 Demo 只输出证据整理、风险提示和人工复核建议，不直接触发退款、补发、拒赔、定责，也不做未成年人资料终审。真实业务处置仍以贵方后台规则、客服负责人和人工复核结论为准。

客服主站的右侧观察面板用于展示服务处理状态。普通演示链接不会展示模型、供应商、Token、接口、成本或内部调参信息。
