# 知识库与视觉识别扩展需求

## 目标结论

本阶段新增两个扩展目标：

| 目标 | 解决的问题 | 验证方式 | 不替代什么 |
| --- | --- | --- | --- |
| 客户自维护知识库 | 客服 SOP、FAQ、商品资料、售后政策、培训文档需要甲方持续维护 | 建设企业知识库层，支持文档入库、混合检索、引用回答、版本回滚和更新审核 | 不替代工单状态机、审批、退款、补发、仓库任务 |
| 三类视觉审核多模态 POC | 视频审核、商品有伤、未成年人资料审核约占 60% 客服人力 | 用多模态理解能力做结构化初筛、证据摘要、置信度、问题时间戳和人工复核建议 | 不自动定责、不自动拒赔、不自动退款、不自动终审未成年人材料 |

## 企业知识库路线

范围：

- 甲方客服负责人可上传 SOP、FAQ、培训文档、售后政策、商品资料、历史优秀工单。
- 支持 PDF、Word、Markdown、表格或导出文本，保留版本、来源和更新时间。
- 支持关键词和语义检索，返回片段、来源文档、页码/章节和置信度。
- 客服系统回答前先检索知识库，回答必须带可追溯依据；低置信度转VIP客服。
- 文档由客服负责人维护，主管审核后生效，旧版本可回滚。

最小验收：

- 至少导入 SOP、FAQ、商品资料、售后政策四类样本。
- 甲方人员可新增、更新、禁用文档。
- 每次回答都能展示引用来源。
- 错误知识更新后可恢复上一版本。
- 至少 50 条问题集，统计命中率、引用正确率和幻觉率。

## 三类视觉审核路线

当前优先验证多模态理解能力对真实业务材料的理解和稳定性，不把识别结果当作最终业务裁决。

| 场景 | 任务 |
| --- | --- |
| 开箱视频/发错货审核 | 对关键片段或抽帧证据输出一镜到底、疑似剪辑、商品离镜、面单可见、瑕疵可见、规格是否匹配、置信度和下一步建议 |
| 商品有伤 | 对用户视频/图片输出损伤类型、位置、严重程度、模糊/反光/遮挡、是否需要补拍 |
| 未成年人资料审核 | 对脱敏材料输出完整性、一致性、疑似篡改、敏感信息遮盖状态，只给人工复核建议 |

边界：

- 不把置信度当终审依据。
- 高敏证件原图默认不送外部通用服务；如需使用，必须由甲方确认脱敏、授权、地域和合规要求。
- 输出只进入人工复核队列或售后证据链。

## 推荐实施顺序

| 阶段 | 目标 | 产出 |
| --- | --- | --- |
| P0-1 | 企业知识库验证 | 文档导入、检索接口、引用回答、50 条问题集评测 |
| P0-2 | 视觉审核快速验证 | 三类视觉场景结构化输出，进入视觉审核工作台 |
| P0-3 | 客服系统接回 | 知识库引用和视觉结论进入 SOP checklist、售后卡片、人工复核任务 |
| P1 | 多候选方案稳定性评测 | 基于甲方标注样本比较速度、成本、命中率、稳定性 |
| P1 | 双盲复核路由 | 主审结果和复核结果交叉验证，低置信度与分歧样本转VIP客服 |

## 甲方需提供材料

| 类别 | 需提供内容 |
| --- | --- |
| 知识库资料 | SOP、FAQ、培训文档、售后政策、商品资料、活动规则、历史优秀工单 |
| 知识库评测集 | 至少 50 条真实客服问题，标注标准答案和引用依据 |
| 视觉样本 | 发错货、商品有伤、开箱视频合规三项，每项至少正负样本各 50 条；评估稳定准确率建议每个结论类 200-300 条 |
| 样本字段 | 用户诉求文本、开箱视频、补充图片、订单商品名、SKU、规格、仓库/商品主数据、最终人工结论、人工结论原因 |
| 合规确认 | 外部识别服务可使用的数据范围、脱敏要求、保存周期、审计要求 |

## 对外说明口径

可以说明：

- 企业知识库能让甲方自己维护 SOP、FAQ、商品资料和政策，并让客服系统基于可追溯来源回答。
- 视觉审核路线适合先快速验证三类视觉审核是否能减负。
- 所有视觉结论都会保留人工复核和审计。

不能说明：

- 知识库可以直接替代客服 SOP 状态机。
- 视觉识别可以自动定责、自动拒赔、自动退款。
- 没有甲方样本和标注也能证明生产准确率。
