客诉审核 Agent 接口联调与商务沟通说明

目标不是替甲方直接退款或拒绝，而是在商品有伤、发错货、漏发货、未成年人资料等场景中，把订单、物流、对话与媒体证据合在一起，给出有理有据、可追溯、可配置的审核建议，并为最终用户沟通提供可靠依据。

先说结论

是的，后台对接以 API 就可以完成，而且这是正式部署最合理的形态。甲方不需要让客服重新手工录订单；甲方系统在出现客诉时，把该案件的订单快照、包裹物流、当前工单对话和全部图片/视频提交给 MITAKO，MITAKO 异步返回结构化建议与可选的人类可读 HTML 报告。

双方应对齐的核心：MITAKO 负责证据审核和沟通建议；甲方负责提供权威业务数据、决定审批规则并执行退款、补发、换货或拒绝等动作。演示网页不是生产数据入口，只是测试和人工复核工具。
扩容边界：当前测试版具备单机任务持久化和异常租约恢复；120GB 级批次或多节点生产运行仍需接入双方确认的对象存储、外部任务队列和共享数据库，当前不宣称已经完成水平扩容。

两类 Agent 各自做什么

审核 Agent

回答“当前证据支持什么”

逐案分析媒体连续性、实际可见商品、订单/SKU、包裹、物流和当前诉求，输出事实结论、证据分数、关键帧、反证、材料缺口和复审等级。

沟通 Agent

回答“如何向用户说明”

客服沟通 API 已独立可用；审核结论自动注入客服会话仍需双方确定会话关联、公开字段和审批规则，当前不宣称已经自动打通。

甲方业务系统

回答“最后怎么处理”

订单、物流、CRM、身份核验和人工客服系统保留最终业务权力，按甲方阈值消费审核建议并执行实际动作。

1. 冻结案件客诉时点生成案件号和证据快照。
2. API 提交每个案件一个异步任务，批量共用批次号。
3. 并行审核媒体预处理、逐帧证据、业务基准并行分析。
4. 返回建议JSON 必返，HTML 可按案件选择。
5. 甲方处理系统自动消费或由 VIP 客服复核。

不同场景，甲方需要提供什么

场景必须或关键的数据数据不足时系统怎么做
发错货应收商品、规格/款式/数量、包裹与商品映射、已提交包裹/运单、用户实际收到物和开箱材料。仍审连续性和可见物，但不会仅凭视频猜订单内容；确定性结论降级。
漏发货完整应发清单、赠品/特典/套装规则、应发包裹数、拆单状态、每包装什么、全部包裹是否签收和展示。有包裹在途或证据未覆盖全部包裹时，先指出缺口，不把“没看到”直接等同“漏发”。
商品有伤争议部位、开箱视频、补充特写、SKU/官方图（增信）、订单和包装标识。分别说明是否看见损伤、能否归因、商品是否离镜。离镜不单独证明调包或欺诈。
未成年人资料五类材料、材料字段、监护关系、订单/支付、手机号归属，以及甲方权威系统的核验结果。明确区分“材料已交”“字段一致”“权威核验通过”；用户自述年龄不等于事实已证明。

历史客诉/风险只接收脱敏统计，只提高抽检优先级，不发送给视觉模型，不改变本次事实结论，也不能自动拒绝。

目前完成了什么，什么还需真实联调

代码已实现
  • 单案、多文件夹和批量异步任务
  • 订单/SKU、应发清单、包裹/物流、工单对话字段
  • 结构化结论、置信度、三级人工复审建议
  • JSON-only 或可选 HTML 报告
  • 幂等、重试、任务状态、成本估算与脱敏日志
  • 模型网关认证、失败重试与降级诊断
等待甲方联调
  • 真实订单与商品主数据接口
  • 商品行到包裹/运单的真实映射
  • 物流轨迹和签收状态
  • 未成年人身份、手机号、订单、支付权威核验
  • 工单对话冻结时点和客服动作回写
  • 审核结果与客服会话自动关联
  • 对象存储、回调鉴权、数据保留和 SLA
不会伪装完成
  • 当前演示数据不等于甲方真实接口已打通
  • HTML 报告不等于自动业务裁决
  • 证据分数不是未经标定的客观正确率
  • 风险用户不等于本次投诉不真实
  • 无法取证时必须显示降级状态

建议的一轮完整迭代

阶段双方工作验收结果
1. 契约沙箱甲方提供脱敏真实 JSON 样例；MITAKO 逐字段校验订单、物流、对话和媒体清单。OpenAPI 导入成功，字段缺失可明确报错，标签不会泄漏。
2. 小批联调四场景各选已复核案件，以异步 API 提交；不把人工结果送入模型。任务独立重试，报告证据可回链，结论可与人工离线比较。
3. 阈值标定按场景统计结论、证据分数、人工复审率和失败类型，确定 required/optional/not_required 阈值。先确定减少多少人工，再决定是否扩大自动消费范围。
4. 灰度上线接入真实对象存储、回调、监控和权限；先只建议，后按甲方规则消费。容量、成本、失败恢复、日志脱敏和数据删除达到验收线。
5. 扩容按实际视频时长和帧密度做并发队列、模型路由与成本预算。单案故障不扩散，批次可观测，120GB 级任务走对象存储/转码链路。

下一次与甲方应确认的事项

业务口径

各场景哪些字段是权威事实；哪些规则只用于补件；哪些置信度进入必审、抽检或可按甲方策略继续。

接口与数据

订单/包裹映射、物流轨迹、商品图、对话快照、身份核验结果的接口样例、版本号、鉴权和脱敏方式。

生产约束

峰值并发、视频大小、对象存储、转码、回调超时、数据保留、审计日志、故障恢复和成本预算。
