四场景审核业务理解与发布验收说明

这份说明面向甲方客服主管、产品和技术人员。它解释当前版本如何盘点材料、处理媒体、调用视觉模型、生成报告，以及哪些内容可以在 JKAdmin 调整。

已完成工程验收八份正式 HTML、API/Web 同源报告、发布门禁和运行包检查已纳入本版本证据。八案用于验证链路和报告质量，不外推生产准确率。

一、当前审核链路

1. 材料盘点
程序先列出视频、图片、订单/SKU、用户诉求、包裹和可选仓库信息；记录文件哈希、重复项、解码状态、图片页数或视频时长。材料不齐先给出具体缺口，不让模型猜。
2. 媒体送审准备
图片逐张转 WebP，不拼成长图；大于 4K 才缩到最长边约 2560。视频达到 100 MB、超过 2K、24 FPS 或 6 Mbps 任一条件时评估完整时长代理，默认 VP9；原片和送审版都留档并可对比。
3. 场景专属事实
模型只提取可见事实、置信度、理由和证据时间点。场景规则与结构化字段契约按四场景分开维护，订单、包裹、年龄、材料齐全和 SOP 决策由程序确定性计算。
4. 报告与人工建议
API 与 Web 使用同一公开数据。首屏只给建议、确定性、材料状态和下一步；详情再展开场景字段、证据预览和原视频跳秒，不展示原始响应、底层配置、访问凭据或个人字段原值。

二、四个场景的业务口径

场景先看什么程序如何收口报告重点
商品有伤是否有初次拆包动作、封箱起始、面单、连续性、争议商品和伤点普通伤缺开箱证据时补件/复核；高置信严重结构伤可进入窄例外；速度或剪辑不可靠只黄标开箱字段、逐伤点、严重程度、成因链、有效展示窗口、原片证据
发错货应收 SKU、同包裹关系、实收商品身份和附件/版本属性按角色、系列、版本、形态、部件逐项对账；静态三图通常到仓库核验，不强制视频应收/实收、同包裹证据、身份差异、仓库或人工下一步
漏发货应发清单、逐包裹实收、分包/赠品规则、商品构成只缺应收项才判漏发路线；仓库终核必须有逐包裹可追溯事实；商品构成不属于应发项时可结束漏发判断用户证据路线、逐包裹差异、仓库状态、纸类后置自查提醒
未成年人退款资料五类材料是否齐全、清晰、主体一致，身份证正反面和订单/支付双门槛可纠正字段点名补件；非标准替代、强冲突和疑似编辑进入人工；未满 10 岁支付过程说明缺失需补，未满 9 岁高置信只提高人工优先级五类交通灯、字段缺口、跨材料冲突、年龄风险和证据，不输出退款批准

三、旧逻辑清理与数据流重构

已清理
退役按场景通用的正负槽位验收、普通伤缺视频直接判负、未成年人材料失败映射为“不支持退款”、把低置信剪辑/速度信号当作事实、把补图证据越级替代主开箱视频，以及 API/Web 各自拼结论。
已重构
四场景规则与字段契约分入口；模型事实、材料齐全、履约对账、仓库终核、人工路由、公开数据和 HTML 渲染分层；每次审核保存原片哈希、送审版哈希和预处理执行结果。
仍有边界
甲方订单、仓库、CRM、历史客诉和客服对话接口目前是契约级设计或模拟适配，不冒充已接通；人工同意/否决/补件/重审的正式事件状态机仍属于后续联调范围。
能力档位
默认使用成本可控档，原生视频按 1 FPS 理解；高质量档只能由超级管理员显式启用，不进入自动兜底。没有稳定盲测分母时，不写准确率百分比。

四、可配置与不可配置

JKAdmin 的“审核策略”页只提供客服主管能理解的业务预算和审核强度，不开放底层指令、字段契约、访问凭据或上游私有参数。

可调整说明
审核强度标准、严格、重点复核三档；只影响证据完整度和人工提示，不绕过场景硬门槛。
视频送审预算原生采样 1 FPS、帧数上限、前置开箱角色预检、100 MB/2K/24 FPS/6 Mbps 评估阈值、VP9/HEVC 送审偏好。
图片送审预算超过 4K 才缩放到 2K 左右，WebP 无损优先，必要时质量 90。
高成本全片抽帧回退默认关闭；只有主管明确开启且记录理由后才允许进入受控回退。

每次发布或回档都要求至少 6 个汉字的理由，记录租户、账号、角色、时间、源版本和目标版本；回档生成新版本，不覆盖历史。

五、建议的测试方式

  1. 商品有伤：分别测试完整开箱、普通伤缺视频、严重结构伤例外、补图同物和三段人为致损；检查伤点与成因是否分开。
  2. 发错货：测试同包裹多 SKU、身份属性相似、静态三图、包裹互换和异常分析模式；检查是否误切漏发。
  3. 漏发货：测试逐包裹视频、静态三图、赠品/分包、商品构成不属于应发项、仓库终核；检查仓库事实是否可追溯。
  4. 未成年人：测试身份证正反面、关系替代、承诺书字段、订单/支付双门槛、手机号例外、未满 10 岁过程说明和未满 9 岁高置信；检查材料问题不被写成退款结论。

每个样本同时看 API JSON、Web 工作台摘要、正式 HTML 首屏和详情，并确认媒体能跳到证据秒数、移动端不横向溢出、公开内容无内部渠道和个人原值。
