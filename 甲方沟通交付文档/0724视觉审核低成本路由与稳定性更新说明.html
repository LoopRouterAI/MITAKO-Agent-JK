低成本路由与稳定性更新

本轮将单模型调用改造为可回退的审核服务，同时保留实际模型、请求耗时、Token 与成本的内部可观测性。网页与标准 API 使用同一套审核核心。

代码已更新 API 与网页已回归 真实多模态请求已验证

这次实际更新了什么

01

优先使用低成本审核模型

日常审核默认走更适合批量抽帧的轻量多模态模型，仍可由部署配置覆盖。

02

通道故障自动回退

首选通道不可用时会转入已配置的备用通道；缺少必需配置的通道不会被误调用。

03

成本统计不再误报

成功调用按实际模型估算。前序通道失败、备用通道成功时，明确标记“部分成本未知”，不会假设失败请求为零成本。

04

旧部署配置仍可使用

兼容原有环境变量和网关配置，升级时不要求甲方立即改造全部配置。

审核任务怎样运行

1. 接收证据包单文件、单工单文件夹或批量工单，同时接收订单与商品上下文。
2. 媒体预处理过滤无效隐藏文件，按策略抽帧、压缩、分段并执行媒体取证。
3. 并发证据审核分别检查事实、连续性、损伤成因、商品对账或未成年人资料一致性。
4. 输出建议返回结论、置信度、证据链、人工复审等级，可选返回 HTML 报告。

本轮交付边界

  • Agent 输出审核建议、置信度和复审建议，不直接执行退款、换货、拒绝售后或赔付。
  • 订单、物流、CRM、客服工单和权威身份核验仍需与甲方真实系统联调；当前演示数据不伪装成已接通生产。
  • 审核服务可以按甲方策略使用结构化 JSON，或同时生成供人工客服阅读的 HTML 证据报告。
