# 甲方 POC 测试说明

版本：2026-07-05
适用对象：甲方客服负责人、业务验收负责人、Java 开发、双方项目经理

## 1. 测试目标

本 POC 只验证“客服 Agent + VIP客服工作台 + 运营后台 + 三类视觉审核工作台”的流程、人效和接口准备度。

不在本轮测试中验证：甲方生产订单写入、真实退款、真实补发、真实拒赔、仓库改状态、财务动作、私域自动触达。

## 4. 建议测试顺序

### A. 页面冒烟

1. 打开四个页面，确认能访问。
2. 页面无明显乱码、白屏、按钮错位。
3. 普通演示页面不展示模型供应商、密钥、Token、内部 Prompt、调试日志。

### B. 客服主链路

建议测试话术：

```text
我的订单清关太慢了，等很久了，能不能帮我催一下？
```

验收点：

- 客服 Agent 能先承接情绪，再解释当前可核实范围。
- 不承诺确定到货时间，不说“外包”“模型”“内部接口”等不该给用户看的内容。
- 能提示需要订单、物流或人工确认的信息。

### C. 转VIP客服链路

1. 在用户端输入“我要转VIP客服”。
2. 在VIP客服工作台接单。
3. 坐席回复一句话。
4. 回到用户端确认能看到VIP客服回复。

验收点：

- 用户端、坐席台状态同步。
- 坐席能看到用户诉求摘要。
- AI 不抢最终业务裁决。

### D. 三类视觉审核

分别测试三个入口：

| 入口 | 建议材料 | 验收点 |
| --- | --- | --- |
| 开箱视频/发错货 | 用户诉求、开箱视频、订单 SKU/规格、补充图片 | 报告先给结论，能说明连续性、离镜/剪辑风险、规格是否匹配 |
| 商品有伤 | 破损图片、视频、包装图 | 能说明损伤位置、证据强弱、是否需要补拍 |
| 未成年人资料 | 脱敏资料、订单归属、付款记录 | 只给材料完整性/一致性建议，必须人工终审 |

验收点：

- 支持上传材料或选择样本文件夹。
- 报告结论置顶，后续是证据链、置信度、缺失材料、人工建议。
- 图片可以预览，视频证据能定位到时间点。
- 高置信只建议抽检；低置信或材料不足必须人工复核。

### E. 接口契约检查

甲方 Java 开发只需先核对：

- `客服Agent与视觉审核对接指南.md` 中的接口方向、字段、鉴权、回调、幂等是否能落地。
- `甲方对接物料与接口清单.md` 中列出的订单、工单、物流、售后、材料接口是否能提供测试环境。
- 写接口上线前是否有禁用开关、回滚流程和人工接管方案。

## 5. 通过标准

| 编号 | 标准 |
| --- | --- |
| P1 | 用户客服端、VIP客服工作台、运营后台、视觉审核工作台均可打开。 |
| P2 | 客服 Agent 能处理物流慢、售后、退货等咨询，并能转VIP客服。 |
| P3 | VIP客服能接单、回复、查看用户诉求摘要。 |
| P4 | 三类视觉审核均能生成客服可读报告。 |
| P5 | 报告不做自动退款、自动拒赔、自动补发、未成年人资料自动终审。 |
| P6 | 甲方开发能根据接口文档列出待提供接口、字段和测试环境。 |
