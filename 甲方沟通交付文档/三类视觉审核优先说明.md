# 三类视觉审核优先说明

## 为什么优先处理三类视觉审核

甲方反馈中，视频审核、商品有伤、未成年人资料审核约占客服人力 60%（约 6 人）。其余客服主链路约占 40%（约 4 人），但每月至少一次爆单时，这 4 人也会临时调去处理视觉审核。因此第一阶段应优先验证三类视觉审核的减负价值。

| 优先级 | 方向 | 目标 |
|--------|------|------|
| P0 | 三类视觉审核减负 | 把人工逐帧看视频、逐张看图片、逐项核资料，变成智能初筛、结构化证据包和人工复核建议。 |
| P0 | 客服主链路抗爆单 | 保留分流、上下文简报、SOP checklist、风险拦截、转人工和排队能力。 |
| P1 | 本地检测路线验证 | 在甲方标注样本足够后，验证高频固定目标识别的速度、成本和隐私收益。 |
| P1 | 客服 SOP 半自动闭环 | 在视觉证据包基础上生成售后处理建议、人工复核任务和质检建议。 |

## 三类业务输出

| 场景 | 输出 | 不做什么 |
|------|------|----------|
| 视频审核 | 一镜到底、六面展示、疑似剪辑、商品离镜、面单可见、瑕疵可见、置信度、处理建议。 | 不自动定责、不自动拒赔、不承诺未验收准确率。 |
| 商品有伤 | 瑕疵是否可见、损伤类型、损伤位置、清晰度、反光/遮挡、补拍或复核建议。 | 不自动补发、不自动换货、不自动赔付。 |
| 未成年人资料审核 | 资料完整性、关系链一致性、敏感信息遮盖、疑似篡改、人工审批建议。 | 不自动退款、不做终审、不处理未脱敏高敏原图。 |

## 对外说明口径

可以说明：

- 我方已经把三类高人力审核拆成独立工作流，能够输出结构化结论、理由、置信度、下一步建议和人工复核标记。
- 这套工作流独立于客服主链路，后续接入真实识别服务时优先替换识别适配层，不重写客服 SOP。
- 对外稳定的是视觉审核结果契约，而不是某个临时样例编号。
- 爆单时，视觉审核队列优先削峰；客服主链路负责分流、保留上下文、阻断高风险动作和转人工。

不能说明：

- 系统可以自动定责、自动拒赔、自动退款、自动补发。
- 当前验证环境已达到甲方真实图片/视频审核准确率。
- 客服主链路可以完全替代爆单时的人工处理。
- 已经接入甲方真实生产后台、真实证件材料或真实退款系统。

## 验收标准

| 验收项 | 标准 |
|--------|------|
| 独立运行 | 视觉审核工作台可独立启动，支持本地视频上传和公开视频链接解析。 |
| 三类覆盖 | 视频审核、商品有伤、未成年人资料审核均有结构化输出。 |
| 分支覆盖 | 覆盖通过、疑似、失败、人工复核、要求补充材料等分支。 |
| 风险边界 | 高风险结论只生成复核建议，不触发真实退款、拒赔、补发、换货。 |
| 敏感信息 | 对外摘要不暴露身份证号、手机号、户口本、出生证明等高敏字段。 |
| 可接回客服 | 输出字段可被客服系统消费，用于售后卡片、人工复核和质检建议。 |

## 甲方需准备的样本

进入真实评测前，建议甲方提供脱敏样本：

| 场景 | 样本建议 |
|------|----------|
| 视频审核 | 正常开箱、疑似剪辑、商品离镜、面单缺失、瑕疵不可见、低清晰度视频。 |
| 商品有伤 | 轻微划痕、中度破损、严重破损、反光遮挡、模糊、错发/漏发图片。 |
| 未成年人资料 | 材料齐全、材料缺失、关系链不成立、疑似篡改、敏感信息未遮盖样本。 |

当前 3 条手工样例只能说明模型方向有信号，不能作为准确率口径。进入准确率评测时，至少需要带人工确认结论的正负样本：

| 评测任务 | 最小样本 | 更稳妥样本 |
|----------|----------|------------|
| 发错货识别 | 确认发错 50 单、确认没发错 50 单 | 每个结论类 200-300 单 |
| 商品有伤识别 | 确认有伤 50 单、确认没伤或不支持 50 单 | 每个结论类 200-300 单 |
| 开箱视频合规 | 合规 50 条、不合规 50 条 | 每个结论类 200-300 条 |

每条样本建议包含：用户诉求文本、开箱视频、用户补充图片、订单商品名、SKU、规格、仓库/商品主数据、最终人工结论、人工结论原因。典型原因包括角色不一致、尺寸口径误会、视频不完整、瑕疵可见但无法证明开箱前存在等。
